# **App Name**: SimuWork

## Core Features:

- Role-Based Simulation: Allow users to select different professional roles for simulation.
- Real Task Integration: Provide a selection of real-world tasks relevant to each role.
- Tool & Workflow Simulation: Simulate the use of industry-standard tools and workflows.
- Personalized Feedback: AI tool which Analyzes user submissions and provide personalized feedback and mentorship.
- Portfolio Output Generation: Generate portfolio-ready outputs based on completed tasks and simulations.
- Progress Tracking: Allow students to view simulation result history and progress over time.

## Style Guidelines:

- Primary color: Dark Indigo (#4B0082) to represent professionalism and trust.
- Background color: Light gray (#F0F0F0), a desaturated version of the primary hue.
- Accent color: Deep Purple (#9400D3) for call-to-action elements and highlights, an analogous color.
- Body and headline font: 'Inter' for a modern and objective feel. Sans-serif.
- Use modern and professional icons representing different industries and roles.
- Clean and structured layout to provide a clear and professional user experience.
- Subtle animations to guide users through the simulation and feedback processes.
